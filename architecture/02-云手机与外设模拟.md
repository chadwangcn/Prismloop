## 一、云手机 Pod 规格配置

### 1.1 Pod 规格矩阵

| Pod 用途 | 规格 | 屏幕布局 | AOSP 版本 | 音视频配置 |
|---|---|---|---|---|
| Guardian APP 测试 | 加强型 | 720×1280 竖屏 | AOSP 11 | 虚拟摄像头+麦克风 |
| K1 设备端模拟 | 加强型 | 640×480 方形 | AOSP 10 | 虚拟摄像头+麦克风 |
| 压测并发 | 加强型 | 同上 | 同上 | 按需 |

### 1.2 K1 屏幕规格定制

**目标**:640×480 方形屏,与 K1 真机一致。

**实现路径**:
1. 联系火山引擎技术支持提交自定义分辨率需求
2. 可能涉及镜像定制(可能收费)
3. 配额申请周期通常 3-5 个工作日

**备选方案**(若火山引擎不支持 640×480):
- 云手机选 720×1280,K1 APP 内部用 SurfaceView 缩放到 640×480 区域
- 视觉 diff 建立双套基线:
  - `visual-baseline/cloud-phone-720x1280/`
  - `visual-baseline/k1-real-640x480/`

### 1.4 IAM 权限边界

- **允许**:ADB 连接、应用安装/卸载/启动/关闭、命令执行、截屏/录屏、屏幕串流、端口映射、备份恢复、查询资源状态
- **拒绝(IAM 策略强制)**:创建/删除实例和主机、购买/退订/续费、构建/删除镜像、重置主机、封禁用户、清空数据、迁移实例
- **其他云服务**(ECS/TOS/IAM/TLS 等):隐式拒绝,已验证返回 403

### 1.5 凭证管理

AK/SK 不入库,存储在 macOS Keychain。Agent 通过 `security find-generic-password` 读取:

```bash
export VOLC_AK=$(security find-generic-password -s "<YOUR_AK_KEYCHAIN_SERVICE>" -w)
export VOLC_SK=$(security find-generic-password -s "<YOUR_SK_KEYCHAIN_SERVICE>" -w)
```

- Keychain 服务名:`<YOUR_AK_KEYCHAIN_SERVICE>` / `<YOUR_SK_KEYCHAIN_SERVICE>`
- 配置文件 `config/env.local.json` 不存储 AK/SK,仅存储 ProductId、Pod ID、EIP 等非敏感信息
- 代码通过 `src/credentials.py` 统一封装 Keychain 读取逻辑

## 二、虚拟摄像头注入

### 2.1 三种注入方式

| 注入方式 | 接入方式 | 适用场景 | 配置要求 |
|---|---|---|---|
| 客户端外部源注入 | ADB 命令推 mp4 文件 / SDK 推流 | 伪直播、固定视频流测试 | 加强型及以上 |
| 客户端内部源注入 | SDK 采集本地真机摄像头/麦克风 | 扫一扫、人脸识别(需真人) | 加强型及以上 |
| Pod 裸数据注入 | Proxy SDK 推 PCM/YUV 裸数据 | 自定义流、RTMP 拉流 | 旗舰型(高负载) |

### 2.2 本方案选型

**优先使用客户端外部源注入**(ADB 推 mp4/m4a),理由:
- 配置要求低(加强型即可)
- 实现简单(ADB 命令)
- 可重复(固定文件)
- 适合自动化测试

### 2.3 视频文件要求

| 项 | 要求 |
|---|---|
| 格式 | .mp4 |
| 编码 | MPEG-4 (m4a/m4v/mp4/3gp) |
| 方向 | 仅竖屏(不支持 rotation) |
| K1 注意 | K1 为方形屏,视频需适配 640×480 |

### 2.4 音频文件要求

| 项 | 要求 |
|---|---|
| 编码 | AAC-LC |
| 采样率 | 16kHz / 32kHz / 44.1kHz / 48kHz |
| 声道 | 单声道或双声道 |
| 采样深度 | 8 位或 16 位 |

### 2.5 ADB 命令注入

```bash
# 连接云手机(需先开通 ADB 公网直连)
adb connect <cloud-phone-eip>:5555

# 推送视频文件到云手机
adb push test-video.mp4 /sdcard/

# 注入视频到虚拟摄像头
adb shell am broadcast -a com.volcengine.vphone.CAMERA_INJECT \
  --es action "start" \
  --es file "/sdcard/test-video.mp4"

# 推送音频文件
adb push test-audio.m4a /sdcard/

# 注入音频到虚拟麦克风
adb shell am broadcast -a com.volcengine.vphone.AUDIO_INJECT \
  --es action "start" \
  --es file "/sdcard/test-audio.m4a"

# 停止注入
adb shell am broadcast -a com.volcengine.vphone.CAMERA_INJECT \
  --es action "stop"
adb shell am broadcast -a com.volcengine.vphone.AUDIO_INJECT \
  --es action "stop"
```

## 三、扬声器输出采集与验证

### 3.1 采集方式

通过客户端 SDK `startRecording` 录制含音频的屏幕录像。

### 3.2 SDK 接口

| 接口 | 用途 |
|---|---|
| `setAudioMute` | 静音开关 |
| `setLocalAudioPlaybackVolume` | 设置本地播放音量 |
| `getLocalAudioPlaybackVolume` | 获取播放音量 |
| `startRecording` / `stopRecording` | 录制云手机画面(含音频) |
| `onAudioStats` | 音频流统计回调(音量、码率) |

### 3.3 ffmpeg 自动分析

```bash
# 下载录像后用 ffmpeg 分析
# 查看音频流信息
ffprobe -i recording.mp4 -show_streams -select_streams a

# 检测音量
ffmpeg -i recording.mp4 -af "volumedetect" -f null /dev/null

# 提取音频轨道
ffmpeg -i recording.mp4 -vn -acodec copy audio.aac

# 分析频率分布
ffmpeg -i recording.mp4 -af "astats=metadata=1:reset=1" -f null /dev/null
```

### 3.4 自动化断言

```python
def analyze_audio(recording_path, expected):
    """分析录像音频,返回断言结果"""
    # 1. 提取音量信息
    result = subprocess.run(
        ["ffmpeg", "-i", recording_path, "-af", "volumedetect", "-f", "null", "/dev/null"],
        capture_output=True, text=True
    )
    
    # 2. 解析音量
    volume = parse_volume_from_ffmpeg_output(result.stderr)
    
    # 3. 断言
    return {
        "mean_volume_db": volume["mean"],
        "max_volume_db": volume["max"],
        "passed": volume["mean"] > expected["min_volume_db"],
        "threshold": expected["min_volume_db"]
    }
```

## 四、物理按键模拟

### 4.1 K1 物理按键映射表

| 物理丝印 | Linux 按键码 | Linux 名称 | Android KeyEvent | keycode | 功能说明 |
|---|---|---|---|---|---|
| 电源 | 0x74 | KEY_POWER | KEYCODE_POWER | 26 | 电源/唤醒/熄屏 |
| 音量+ | 0x73 | KEY_VOLUMEUP | KEYCODE_VOLUME_UP | 24 | 音量增加 |
| 音量- | 0x72 | KEY_VOLUMEDOWN | KEYCODE_VOLUME_DOWN | 25 | 音量减小 |
| AI | 0x43 | KEY_F9 | KEYCODE_F9 | 67 | AI 语音唤醒键 |
| 拍照 | 0x8b | KEY_F12 | KEYCODE_F12 | 139 | 相机拍照快捷键 |

#### 方式一:SDK sendKeyCode(推荐,生产可用)

```python

# 长按(单状态)
sdk.sendKeyCode(keycode=67, action="down")

sdk.sendKeyCode(keycode=67, action="up")
```

#### 方式二:ADB input keyevent(调试用)

```bash
adb shell input keyevent 67  # AI 键

adb shell input keyevent 24  # 音量+
```

## 六、ADB 公网直连(调试用)

### 6.1 前提

- 通过 ACEP OpenAPI 启用 Pod ADB:
  1. `add_adb_key`(一次性,上传本地 `~/.android/adbkey.pub`)
  2. `bind_adb_key_pods`(把 key 绑定到指定 Pod)
  3. `pod_adb(enable=True)` 返回连接地址
- ADB 有过期时间,过期后重新调用 `pod_adb(enable=True)`
- 4 台 Pod 共享同一 EIP(`<YOUR_SHARED_EIP>`),通过不同端口映射区分

### 6.2 常用命令

```bash
# 连接云手机(地址由 pod_adb(enable=True) 返回,非固定 5555)
adb connect <pod_adb_address>

# 点击坐标
adb shell input tap 540 960

# 滑动
adb shell input swipe 540 1800 540 600 300

# 长按
adb shell input swipe 540 960 540 960 1000

# 多点触控(需 Android 7+)
adb shell input swipe 200 800 300 800 100 & \
adb shell input swipe 880 800 780 800 100

# 按键
adb shell input keyevent KEYCODE_BACK      # 返回 4
adb shell input keyevent KEYCODE_HOME       # Home 3
adb shell input keyevent KEYCODE_MENU       # 菜单 82
adb shell input keyevent KEYCODE_POWER      # 电源 26
adb shell input keyevent KEYCODE_VOLUME_UP  # 音量+ 24
adb shell input keyevent KEYCODE_VOLUME_DOWN # 音量- 25
adb shell input keyevent KEYCODE_CAMERA     # 相机 27
adb shell input keyevent KEYCODE_CALL       # 拨号 5
adb shell input keyevent KEYCODE_ENTER      # 回车 66

# 输入文本(仅英文/数字)
adb shell input text "hello"

# 中文输入(需 ADBKeyboard)
adb shell am broadcast -a ADB_INPUT_TEXT --es msg "中文测试"

# 截图
adb shell screencap -p /sdcard/screen.png
adb pull /sdcard/screen.png /tmp/

# 录屏(Android 4.4+)
adb shell screenrecord /sdcard/demo.mp4 --time-limit 30
adb pull /sdcard/demo.mp4 /tmp/
```

### 6.3 使用约束

- **仅供调试目的**,火山引擎声明不建议用于生产环境
- 地址由 ACEP `pod_adb(enable=True)` 动态返回,有过期时间,过期重新调用
- 生产测试用 MUA OpenAPI + ACEP OpenAPI

## 八、音视频测试硬约束

| 约束 | 说明 |
|---|---|
| 仅支持竖屏 | 横屏模式音视频注入显示异常 |
| 注入源互斥 | 同一时间只能用一种注入方式,切换需先关闭摄像头和麦克风 |
| 配置要求 | 加强型及以上,高负载场景用旗舰型 |
| 应用加签 | 自主开发的应用需在控制台完成应用加签(第三方应用无需) |
| 文件格式严格 | 视频 mp4/MPEG-4,音频 AAC-LC,需预处理 |
| 高安全人脸识别 | 不支持支付级别,需自行评估 |
| K1 方形屏适配 | 视频需适配 640×480 方形分辨率 |

## 九、SDK Bridge(可选事件级输入扩展)

> 本章为可选扩展。当前 P5 环境使用 ACEP OpenAPI,不依赖 SDK Bridge。

### 9.1 用途

ACEP OpenAPI 是管理级接口,不直接暴露 `sendKeyCode` / `sendMouseKey` / `sendMulitTouch` 等事件级输入。如需事件级精确控制(如长按 DOWN/UP 时序、多点触控、输入法组合事件),有两种选择:

| 方式 | 说明 | 推荐度 |
|---|---|---|
| ADB `input` 命令 | `adb shell input tap/swipe/keyevent`(经 ACEP `run_sync_command` 或直连 ADB) | 默认 |
| SDK Bridge | 部署自建 HTTP Bridge 桥接 Native SDK,暴露 RESTful 接口 | 需要时 |

### 9.2 SDK Bridge 架构(可选)

```
┌─────────────────┐     HTTP     ┌──────────────────┐     Native    ┌─────────┐
│  SDKClient       │ ─────────► │  SDK Bridge       │ ───────────► │  云手机  │
│  (src/sdk_client)│            │  (自建桥接服务)    │              │  Pod    │
└─────────────────┘             └──────────────────┘              └─────────┘
```

事件接口清单(`src/sdk_client.py` 默认封装):
`sendKeyCode`、`sendMouseKey`、`sendMouseMove`、`sendMouseWheelArm`、`sendMulitTouch`、`sendImeComposition`、`sendEditTextInput`、`sendClipBoardMessage`、`sendShakeEventToRemote`、`rotateScreen`、`setNavBarStatus`、`launchApp`、`closeApp`、`setRemoteForeground`、`screenShot`、`startRecording`、`stopRecording`

### 9.3 默认实现策略

当前代码默认走 ACEP OpenAPI + ADB:
- 输入事件 → ACEP `run_sync_command` 或 ADB `input`
- 截屏 → ACEP `batch_screen_shot`
- 录屏 → ACEP `start_recording` / `stop_recording`
- 应用安装 → ACEP `upload_app` + `install_app`
- 文件推送 → ACEP `push_file`(URL 分发)

`src/sdk_client.py` 的 HTTP Bridge 封装保留,标注为"可选扩展",默认不启用。

## 十、ACEP OpenAPI 接入方式

### 10.1 SDK 安装

```bash
pip install volcengine-python-sdk
```

主要模块:`volcenginesdkacep`

### 10.2 初始化

```python
import subprocess
import volcenginesdkacep as acep
from volcenginesdkcore import ApiClient, Configuration

# 从 Keychain 读取凭证
ak = subprocess.check_output(
    ["security","find-generic-password","-s",
     "<YOUR_AK_KEYCHAIN_SERVICE>","-w"], text=True).strip()
sk = subprocess.check_output(
    ["security","find-generic-password","-s",
     "<YOUR_SK_KEYCHAIN_SERVICE>","-w"], text=True).strip()

cfg = Configuration()
cfg.ak = ak
cfg.sk = sk
cfg.region = "cn-shanghai"
api = acep.ACEPApi(ApiClient(cfg))

PRODUCT_ID = "<YOUR_PRODUCT_ID>"
POD_K1 = "<K1_POD_ID>"
POD_K1_BACKUP = "<K1_BACKUP_POD_ID>"
POD_APP_LANDSCAPE = "<GUARDIAN_LANDSCAPE_POD_ID>"
POD_APP_PORTRAIT = "<GUARDIAN_PORTRAIT_POD_ID>"
```

### 10.3 常用操作

```python
# 查询实例状态
pod = api.detail_pod(acep.DetailPodRequest(
    product_id=PRODUCT_ID, pod_id=POD_K1)).pod
print(pod.online, pod.intranet_ip, pod.eip.eip_address)

# 开机/关机/重启(注意:pod_id_list 是列表)
api.power_on_pod(acep.PowerOnPodRequest(
    product_id=PRODUCT_ID, pod_id_list=[POD_K1]))
api.power_off_pod(acep.PowerOffPodRequest(
    product_id=PRODUCT_ID, pod_id_list=[POD_K1]))
api.reboot_pod(acep.RebootPodRequest(
    product_id=PRODUCT_ID, pod_id_list=[POD_K1]))

# 执行 Shell 命令(注意:pod_id_list 是列表)
resp = api.run_sync_command(acep.RunSyncCommandRequest(
    product_id=PRODUCT_ID,
    pod_id_list=[POD_K1],
    command="getprop ro.build.version.release"))
print(resp.status, resp.command)

# 截屏
resp = api.batch_screen_shot(acep.BatchScreenShotRequest(
    product_id=PRODUCT_ID,
    pod_id_list=[POD_K1],
    is_saved_on_pod=True))
for d in resp.details:
    print(d)

# 录屏
api.start_recording(acep.StartRecordingRequest(
    product_id=PRODUCT_ID, pod_id=POD_K1, duration_limit=60))
# ... 执行测试操作 ...
api.stop_recording(acep.StopRecordingRequest(
    product_id=PRODUCT_ID, pod_id=POD_K1))

# 屏幕串流(投屏)
resp = api.get_pre_signed_edge_url(acep.GetPreSignedEdgeURLRequest(
    product_id=PRODUCT_ID, pod_id=POD_K1, ttl=3600))
print(resp.pre_signed_edge_url)
```

### 10.4 ADB 启用流程

```python
# 1. 添加 ADB 公钥(只需一次)
api.add_adb_key(acep.AddAdbKeyRequest(
    product_id=PRODUCT_ID,
    key_name="agent-adb-key",
    public_key=open(os.path.expanduser("~/.android/adbkey.pub")).read()
))

# 2. 绑定 Key 到 Pod
api.bind_adb_key_pods(acep.BindAdbKeyPodsRequest(
    product_id=PRODUCT_ID,
    key_id="<adb_key_id>",
    pod_id_list=[POD_K1]
))

# 3. 开启 ADB(enable=True 返回连接地址)
resp = api.pod_adb(acep.PodAdbRequest(
    product_id=PRODUCT_ID,
    pod_id=POD_K1,
    enable=True
))
# resp 中包含 ADB 连接地址(ip:port)
# 本地执行:adb connect <address>
```

### 10.5 应用安装(URL 分发)

> 云手机通过 URL 分发应用,**不支持本地文件直传**。APK 需先上传到可下载地址(TOS/CDN)。

```python
# 1. 注册应用(提供 APK 下载 URL)
api.upload_app(acep.UploadAppRequest(
    product_id=PRODUCT_ID,
    app_name="K1 Test App",
    app_type="apk",
    download_url="https://example.com/app.apk",
    parse_flag=True
))

# 2. 安装到指定 Pod
api.install_app(acep.InstallAppRequest(
    product_id=PRODUCT_ID,
    pod_id_list=[POD_K1],
    app_id="<app_id>",
    version_id="<version_id>"
))

# 3. 启动/关闭应用
api.launch_app(acep.LaunchAppRequest(
    product_id=PRODUCT_ID,
    pod_id_list=[POD_K1],
    package_name="com.example.app"
))
api.close_app(acep.CloseAppRequest(
    product_id=PRODUCT_ID,
    pod_id_list=[POD_K1],
    package_name="com.example.app"
))
```

### 10.6 文件推送(URL 分发)

> 文件也通过 URL 分发,**不支持本地路径直传**。

```python
api.push_file(acep.PushFileRequest(
    product_id=PRODUCT_ID,
    pod_id_list=[POD_K1],
    download_url="https://example.com/testdata.zip",
    file_name="testdata.zip",
    target_directory="/sdcard/Download/",
    auto_unzip=True
))
```

### 10.8 注意事项

- 所有 API 调用必须传 `product_id=<YOUR_PRODUCT_ID>`
- `pod_id_list` 参数是列表,即使操作单个 Pod 也需 `[POD_K1]`
- ADB 地址由 `pod_adb(enable=True)` 动态返回,有过期时间
- 文件和 APK 分发通过 URL,不支持本地路径直传;需先上传到可下载地址
- 4 台 Pod 共享同一 EIP,通过不同端口映射区分
- 测试数据及时清理;`PodDataDelete`(清空数据)已被 IAM 策略禁止
- 遇到权限不足检查 IAM 策略 `lumi-test-cloudphone-scoped`,不要使用管理员凭证
