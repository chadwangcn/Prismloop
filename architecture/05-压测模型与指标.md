## 一、压测模型

### 1.1 压测目标

- 验证 Device Platform 在高并发下的稳定性
- 验证 Guardian APP 与 K1 设备端的协同链路在压力下的表现
- 采集 SLA 指标(响应时间、成功率、错误率)
- 发现性能瓶颈与资源限制

### 1.2 压测约束

| 约束 | 说明 |
|---|---|
| MUA RunAgentTask 单用户 QPS | 10/s |
| 单任务 MaxStep | 500 |
| 单任务 Timeout | 86400 秒(24 小时) |
| 云手机实例规格 | 8vCPU/24GB/256GB(固定) |
| 并发上限 | 受 Pod 数量限制 |

### 1.3 并发策略

由于单用户 QPS 限制 10/s,高并发压测采用:

1. **申请多个子账号**:每个子账号独立 AK/SK,QPS 独立计算
2. **阶梯加压**:10 → 30 → 50 → 100 并发,每档稳定 5 分钟
3. **任务排队**:超过 QPS 限制时,本地排队等待

## 三、压测控制器架构

### 3.1 架构图

```
┌─────────────────────────────────────────────────────┐
│              PressureController                      │
├─────────────────────────────────────────────────────┤
│  - acquire_pods(n)          # 从云手机池申请 n 个 Pod │
│  - distribute_tasks(cases)  # 任务分发               │
│  - rate_limiter             # QPS 限流               │
│  - stepwise_pressure        # 阶梯加压               │
│  - collect_results(run_ids) # 聚合结果              │
│  - metrics                 # 指标采集               │
│  - report                  # 报告生成               │
└─────────────────────────────────────────────────────┘
```

### 3.2 核心类设计

```python
class PressureController:
    """压测控制器"""
    
    def __init__(self, mua_clients, sdk_clients, pod_pool):
        """
        mua_clients: 多账号 MUA 客户端列表(突破 QPS 限制)
        sdk_clients: SDK 客户端
        pod_pool: Pod 池
        """
        self.mua_clients = mua_clients
        self.sdk_clients = sdk_clients
        self.pod_pool = pod_pool
        self.rate_limiter = RateLimiter(qps=10 * len(mua_clients))
    
    def run_pressure_test(self, scenario, pairs_count, 
                           ramp_up_sec, steady_sec):
        """执行压测"""
        # 1. 申请 Pod 对
        pairs = self.pod_pool.acquire_pairs(pairs_count)
        
        # 2. 阶梯加压
        stages = self._build_stages(
            pairs, ramp_up_sec, steady_sec
        )
        
        # 3. 执行各阶段
        results = []
        for stage in stages:
            stage_results = self._run_stage(stage, scenario)
            results.extend(stage_results)
        
        # 4. 聚合指标
        metrics = self._aggregate_metrics(results)
        
        # 5. 生成报告
        report = self._generate_report(metrics, scenario)
        
        # 6. 释放 Pod
        self.pod_pool.release_pairs(pairs)
        
        return report
    
    def _run_stage(self, stage, scenario):
        """执行单个压测阶段"""
        with ThreadPoolExecutor(max_workers=stage.concurrency) as executor:
            futures = []
            for pair in stage.pairs:
                self.rate_limiter.acquire()
                future = executor.submit(
                    self._execute_scenario, scenario, pair
                )
                futures.append(future)
            
            results = []
            for future in as_completed(futures, timeout=stage.timeout):
                results.append(future.result())
            
            return results
```

### 3.3 阶梯加压

```python
def _build_stages(self, pairs, ramp_up_sec, steady_sec):
    """构建阶梯加压阶段"""
    total_pairs = len(pairs)
    stages = []
    
    # 阶梯:10% → 30% → 50% → 100%
    levels = [0.1, 0.3, 0.5, 1.0]
    ramp_per_level = ramp_up_sec / len(levels)
    
    for i, level in enumerate(levels):
        n = int(total_pairs * level)
        stages.append(Stage(
            name=f"ramp_{int(level*100)}",
            pairs=pairs[:n],
            concurrency=n,
            duration_sec=ramp_per_level,
            timeout=ramp_per_level + 60
        ))
    
    # 稳定期
    stages.append(Stage(
        name="steady",
        pairs=pairs,
        concurrency=total_pairs,
        duration_sec=steady_sec,
        timeout=steady_sec + 60
    ))
    
    return stages
```

### 4.3 指标采集实现

```python
class MetricsCollector:
    """指标采集器"""
    
    def __init__(self):
        self.results = []
        self.start_time = None
        self.end_time = None
    
    def record(self, task_result):
        """记录单个任务结果"""
        self.results.append({
            "run_id": task_result["run_id"],
            "is_success": task_result["is_success"],
            "latency_ms": task_result["latency_ms"],
            "error_type": task_result.get("error_type"),
            "in_tokens": task_result["usage"]["in_tokens"],
            "out_tokens": task_result["usage"]["out_tokens"]
        })
    
    def aggregate(self, scenario, concurrency, duration_sec):
        """聚合指标"""
        latencies = [r["latency_ms"] for r in self.results]
        success_count = sum(1 for r in self.results if r["is_success"])
        failure_count = len(self.results) - success_count
        
        # 错误分类
        error_types = {}
        for r in self.results:
            if not r["is_success"] and r["error_type"]:
                error_types[r["error_type"]] = \
                    error_types.get(r["error_type"], 0) + 1
        
        return {
            "scenario": scenario,
            "concurrency": concurrency,
            "duration_sec": duration_sec,
            "total_tasks": len(self.results),
            "success_count": success_count,
            "failure_count": failure_count,
            "success_rate": success_count / len(self.results),
            "latency": {
                "p50_ms": percentile(latencies, 50),
                "p95_ms": percentile(latencies, 95),
                "p99_ms": percentile(latencies, 99),
                "min_ms": min(latencies),
                "max_ms": max(latencies)
            },
            "errors": [
                {"type": k, "count": v} 
                for k, v in error_types.items()
            ],
            "resource_usage": {
                "avg_in_tokens": mean([r["in_tokens"] for r in self.results]),
                "avg_out_tokens": mean([r["out_tokens"] for r in self.results]),
                "total_in_tokens": sum(r["in_tokens"] for r in self.results),
                "total_out_tokens": sum(r["out_tokens"] for r in self.results)
            }
        }
```

## 六、Pod 资源池管理

### 6.1 Pod 池设计

```python
class PodPool:
    """云手机 Pod 资源池"""
    
    def __init__(self, mua_client):
        self.mua_client = mua_client
        self.guardian_pods = []
        self.k1_pods = []
        self.acquired_pairs = []
    
    def acquire_pairs(self, count):
        """申请 n 对 Pod"""
        # 检查可用 Pod
        available_guardian = [
            p for p in self.guardian_pods 
            if p not in self.acquired_pairs
        ]
        available_k1 = [
            p for p in self.k1_pods 
            if p not in self.acquired_pairs
        ]
        
        if len(available_guardian) < count or len(available_k1) < count:
            raise InsufficientPodsError(
                f"需要 {count} 对,可用 Guardian {len(available_guardian)}, "
                f"K1 {len(available_k1)}"
            )
        
        pairs = []
        for i in range(count):
            pair = {
                "pair_id": f"pair-{uuid4().hex[:8]}",
                "guardian_pod": available_guardian[i],
                "k1_pod": available_k1[i]
            }
            pairs.append(pair)
            self.acquired_pairs.append(pair)
        
        return pairs
    
    def release_pairs(self, pairs):
        """释放 Pod 对"""
        for pair in pairs:
            self.acquired_pairs.remove(pair)
```

## 八、与已有 k6 压测的关系

| 维度 | k6(已有) | MUA 压测(本方案) |
|---|---|---|
| 测试层 | 后端 API(HTTP) | APP 端到端(含 UI) |
| 并发模型 | HTTP 请求 | MUA 任务 |
| 成本 | 低 | 高(云手机实例) |
| 覆盖 | API 层 | APP 客户端 + 网络协同 |
| 用途 | API 压测 | APP 压测 |

**互补关系**:API 层用 k6,APP 层用 MUA,不重复。
