## 一、双端协同模型

### 1.1 双端角色

| 端 | 角色 | 设备形态 | APK | 核心职责 |
|---|---|---|---|---|
| **Guardian APP** | 家长端 | 标准手机 720×1280 竖屏 | Guardian.apk | 远程管理、查看报告、配置策略 |
| **K1 设备端** | 儿童端 | 方形手表 640×480 | K1-Device.apk | 内容播放、AI 交互、拍照、语音 |

### 1.2 协同关系

```
┌─────────────────┐                    ┌─────────────────┐
│  Guardian APP    │◄─── Identity/ ───►│   K1 设备端      │
│  (家长端)        │     Device         │  (儿童端)        │
│                  │     Platform        │                  │
│  - 绑定 K1        │◄───── S2/S5 ──────►│  - 设备激活       │
│  - 查看成长报告    │     公共 API         │  - 内容接收       │
│  - 配置内容策略    │                    │  - AI 交互        │
│  - 远程指令       │◄───── 控制通道 ────►│  - 拍照/录音       │
│                  │                    │  - 物理按键触发    │
└────────┬─────────┘                    └────────┬────────┘
         │                                       │
         │  测试仅通过 UI 操作和截图验证            │
         │  不注册 webhook,不查询后端 API          │
         └───────────────────────────────────────┘
```

### 1.3 核心约束

**测试不影响正常业务**:
- ❌ 不在 Device Platform 注册 webhook
- ❌ 不查询后端 API 验证状态
- ✅ 纯用户视角,通过 UI 截图轮询验证

## 二、协同场景矩阵

### 2.1 场景分类

| 场景类 | 触发端 | 响应端 | 协同通道 | 验证点 |
|---|---|---|---|---|
| 绑定协同 | Guardian APP | K1 设备端 | Device Platform API | 双端绑定状态一致 |
| 内容下发 | Guardian APP | K1 设备端 | S5 Content API | K1 收到内容并展示 |
| 报告回传 | K1 设备端 | Guardian APP | S2 Guardian API | 家长端看到 K1 活动 |
| 远程指令 | Guardian APP | K1 设备端 | S6 Schedule API | K1 执行指令并反馈 |
| 物理按键 | K1 设备端(物理) | Guardian APP | S2 事件 | 家长端收到按键事件通知 |
| 拍照回传 | K1 设备端(拍照键) | Guardian APP | S5 Upload API | 家长端看到照片 |

### 2.2 协同时序约束

| 协同操作 | 最大延迟 | 超时处理 |
|---|---|---|
| 绑定同步 | 5 秒 | 标记为 flaky,重试 1 次 |
| 内容下发 | 30 秒 | 标记为 timeout,失败 |
| 状态回传 | 10 秒 | 标记为 timeout,重试 1 次 |
| 拍照上传 | 60 秒 | 标记为 timeout,失败 |
| 远程指令执行 | 30 秒 | 标记为 timeout,失败 |

### 2.3 数据一致性约束

- 双端 `device_sn` 必须一致
- 双端 `family_id` / `child_id` 必须一致
- 双端 `binding_version` 必须一致
- 双端 `credential_version` 必须一致

## 三、轮询驱动等待机制

### 3.1 核心实现

```python
def wait_for_pod_state(pod, expected_state, timeout_sec=30, interval_sec=2):
    """从 Pod UI 轮询状态,不依赖后端回调"""
    start = time.time()
    while time.time() - start < timeout_sec:
        screenshot = sdk.screenShot(pod)
        if mua_visual_check(screenshot, expected_state):
            return True
        time.sleep(interval_sec)
    return False
```

### 3.2 视觉检测实现

```python
def mua_visual_check(screenshot, expected_state):
    """使用 MUA 视觉理解检测截图状态"""
    prompt = f"判断截图中是否显示'{expected_state}',返回 JSON: {{'matched': true/false}}"
    result = mua.run_task_one_step(
        pod_id="vision-check-pod",  # 专用检测 Pod
        user_prompt=prompt,
        output_schema={
            "Type": "dict",
            "Fields": [
                {"Name": "matched", "Type": "boolean", "Required": True}
            ]
        }
    )
    return result["struct_output"]["matched"]
```

### 3.3 协同场景等待策略

| 协同场景 | 触发端 | 响应端验证(轮询 UI) | 超时 |
|---|---|---|---|
| 绑定 | Guardian 扫码 | K1 每 2 秒截图,检测"已绑定"提示 | 30 秒 |
| 内容下发 | Guardian 下发 | K1 每 2 秒截图,检测内容到达 | 30 秒 |
| 远程指令 | Guardian 下发 | K1 每 2 秒截图,检测"休息时间"提示 | 30 秒 |
| 拍照回传 | K1 拍照 | Guardian 每 2 秒截图,检测新照片出现 | 60 秒 |
| 报告回传 | K1 活动 | Guardian 每 2 秒截图,检测报告刷新 | 30 秒 |

### 3.4 局限与补偿

**局限**:
- 2 秒间隔可能错过瞬时状态(如加载动画)
- 截图检测依赖 MUA 视觉理解,成功率 97.4%(非 100%)

**补偿措施**:
- 关键状态用 MUA + 视觉 diff 双重验证
- 超时后自动重试 1 次,仍失败才标记为 real failure
- 弱网场景单独测试,超时延长至 60 秒

## 四、双端测试编排架构

### 4.1 编排器设计

```
┌─────────────────────────────────────────────────────┐
│              DualEndOrchestrator                     │
├─────────────────────────────────────────────────────┤
│  - 双端用例解析(topology + steps + wait_for)         │
│  - 双 Pod 并行/串行调度                              │
│  - 跨端等待机制(poll_ui 轮询)                       │
│  - 协同断言(dual_screenshot + state compare)         │
│  - 物理按键调度(SDK sendKeyCode)                     │
│  - 音视频注入协调(ADB broadcast)                     │
│  - 证据聚合(guardian-ss + k1-ss + recordings)        │
└─────────────────────────────────────────────────────┘
```

### 4.2 编排器核心类

```python
class DualEndOrchestrator:
    """双端协同测试编排器"""
    
    def __init__(self, mua_client, sdk_client, pod_pool):
        self.mua = mua_client
        self.sdk = sdk_client
        self.pods = pod_pool
    
    def execute_case(self, case):
        """执行双端用例"""
        # 1. 解析拓扑
        pair = self.pods.acquire_pair()
        
        # 2. 执行前置条件
        self._setup_preconditions(case, pair)
        
        # 3. 注入音视频(如有)
        self._inject_assets(case, pair)
        
        # 4. 执行步骤
        results = []
        for step in case["steps"]:
            result = self._execute_step(step, pair)
            results.append(result)
            
            if not result["passed"] and step.get("stop_on_fail", False):
                break
        
        # 5. 执行协同断言
        dual_results = self._execute_dual_assertions(
            case.get("dual_assertions", []), pair
        )
        
        # 6. 清理
        self._teardown(case, pair)
        
        # 7. 聚合结果
        return self._aggregate_result(case, results, dual_results)
    
    def _execute_step(self, step, pair):
        """执行单个步骤"""
        pod = pair[step["pod"]]
        method = step["method"]
        
        if method == "mua":
            return self._execute_mua_step(step, pod)
        elif method == "sdk":
            return self._execute_sdk_step(step, pod)
        elif method == "adb":
            return self._execute_adb_step(step, pod)
        elif method == "poll_ui":
            return self._execute_poll_step(step, pod)
    
    def _execute_poll_step(self, step, pod):
        """执行轮询步骤"""
        start = time.time()
        timeout = step.get("timeout_sec", 30)
        interval = step.get("interval_sec", 2)
        check = step["check"]
        
        while time.time() - start < timeout:
            screenshot = self.sdk.screenShot(pod)
            if self.mua_visual_check(screenshot, check["description"]):
                return {
                    "passed": True,
                    "duration_sec": time.time() - start,
                    "screenshot": screenshot
                }
            time.sleep(interval)
        
        return {
            "passed": False,
            "duration_sec": timeout,
            "screenshot": screenshot,
            "error": "timeout"
        }
```

## 六、双端证据采集

### 6.1 双端截图

```python
def collect_dual_screenshot(guardian_pod, k1_pod):
    """同时采集双端截图"""
    from concurrent.futures import ThreadPoolExecutor
    
    with ThreadPoolExecutor(max_workers=2) as executor:
        guardian_future = executor.submit(
            self.sdk.screenShot, guardian_pod
        )
        k1_future = executor.submit(
            self.sdk.screenShot, k1_pod
        )
        
        return {
            "guardian": guardian_future.result(),
            "k1": k1_future.result(),
            "timestamp": time.time()
        }
```

### 6.2 双端录像

```python
def collect_dual_recording(guardian_pod, k1_pod, duration_sec=60):
    """同时录制双端"""
    # 1. 同时启动录像
    self.sdk.startRecording(guardian_pod)
    self.sdk.startRecording(k1_pod)
    
    # 2. 等待指定时长
    time.sleep(duration_sec)
    
    # 3. 同时停止录像
    guardian_recording = self.sdk.stopRecording(guardian_pod)
    k1_recording = self.sdk.stopRecording(k1_pod)
    
    return {
        "guardian": guardian_recording,
        "k1": k1_recording,
        "duration_sec": duration_sec
    }
```

### 6.3 协同断言

```python
def assert_state_consistency(guardian_state, k1_state, fields):
    """验证双端状态一致性"""
    for field in fields:
        guardian_value = guardian_state.get(field)
        k1_value = k1_state.get(field)
        
        if guardian_value != k1_value:
            return {
                "passed": False,
                "field": field,
                "guardian_value": guardian_value,
                "k1_value": k1_value
            }
    
    return {"passed": True}
```

### 7.2 配对管理

```python
class PodPairManager:
    """Pod 配对管理器"""
    
    def __init__(self, pod_pool):
        self.pod_pool = pod_pool
        self.active_pairs = {}
    
    def acquire_pair(self, pair_id=None):
        """申请一对 Pod"""
        if pair_id and pair_id in self.active_pairs:
            return self.active_pairs[pair_id]
        
        pair = self.pod_pool.acquire_pair()
        self.active_pairs[pair["pair_id"]] = pair
        return pair
    
    def release_pair(self, pair_id):
        """释放一对 Pod"""
        if pair_id in self.active_pairs:
            self.pod_pool.release_pair(self.active_pairs[pair_id])
            del self.active_pairs[pair_id]
```

## 八、云手机模拟 K1 的局限

### 8.1 无法模拟的维度

| 维度 | 影响 | 补偿方案 |
|---|---|---|
| 1.8GB RAM | OOM 风险不可见 | 真机 K1 补充性能测试 |
| 展锐 SL8541E SoC | 架构差异 | 真机 K1 补充兼容性测试 |
| Android 8.1(API 27) | API 27 以下特性不可测 | 云手机选 AOSP 10,接受差异 |
| 物理硬件按键触感 | 物理交互体验不可测 | 真机 K1 补充体验测试 |

### 8.2 测试覆盖策略

- **云手机负责 80%**:协同逻辑测试(UI、按键、音视频、网络协同)
- **真机 K1 负责 20%**:性能与兼容性测试(RAM、SoC、API 27、硬件体验)
