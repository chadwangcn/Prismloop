# 管理后台集成规划

> 文档版本:v1.0
> 创建日期:2026-08-06
> 适用范围:测试系统与管理后台的集成(长远规划)

---

## 一、规划目标

### 1.1 长远定位

整套测试系统未来会**集成到管理后台**,实现:
- 管理后台可**执行测试用例**、下发指令
- 管理后台可**查看测试界面**和结果
- 全程 Agent 驱动,无需人工操作

### 1.2 规划原则

- **渐进式集成**:分阶段实现,不一次性铺开
- **API First**:先定义 API 契约,后实现界面
- **职责分离**:管理后台负责控制,测试系统负责执行
- **复用现有 Agent**:基于已有的 Agent 驱动模型扩展

---

## 二、集成阶段规划

### 2.1 阶段划分

| 阶段 | 目标 | 优先级 |
|---|---|---|
| **阶段一:API 暴露** | 测试系统通过 API 暴露能力 | P0 |
| **阶段二:基础控制** | 管理后台可触发测试、查看结果 | P1 |
| **阶段三:实时界面** | 管理后台可实时查看测试执行 | P2 |
| **阶段四:完整集成** | 管理后台全功能集成 | P3 |

### 2.2 阶段一:API 暴露

测试系统对外暴露 RESTful API,管理后台通过 API 调用。

**核心 API**:

| API | 方法 | 用途 |
|---|---|---|
| `/api/v1/tasks` | POST | 创建测试任务 |
| `/api/v1/tasks/{id}` | GET | 查询任务状态 |
| `/api/v1/tasks/{id}/result` | GET | 获取任务结果 |
| `/api/v1/tasks/{id}/cancel` | POST | 取消任务 |
| `/api/v1/tasks` | GET | 列出任务 |
| `/api/v1/test-cases` | GET | 列出测试用例 |
| `/api/v1/test-cases/{id}` | GET | 获取用例详情 |
| `/api/v1/pods` | GET | 列出 Pod 资源 |
| `/api/v1/reports/{id}` | GET | 获取测试报告 |

### 2.3 阶段二:基础控制

管理后台基础功能:
- 触发测试(选择用例 + 选择 Pod)
- 查看任务列表
- 查看任务结果(JSON + 截图)
- 查看历史报告

### 2.4 阶段三:实时界面

管理后台实时功能:
- 实时查看 Pod 屏幕(推流)
- 实时查看任务执行日志
- 实时查看断言结果

### 2.5 阶段四:完整集成

管理后台完整功能:
- 测试用例管理(CRUD)
- Pod 资源池管理
- 测试计划调度
- 测试报告可视化
- 压测仪表盘
- 异常告警

## 三、API 契约设计

### 3.1 创建测试任务

```
POST /api/v1/tasks
Content-Type: application/json
```

**请求体**:

```json
{
  "task_name": "语音消息功能验证",
  "task_type": "unit_functional",
  "priority": "P0",
  "target_pods": {
    "guardian": "pod-guardian-01",
    "k1": "pod-k1-01"
  },
  "build_manifest": {
    "commit_sha": "abc123",
    "manifest_path": "tos://<YOUR_BUILDS_BUCKET>/abc123/build-manifest.json"
  },
  "test_cases": ["GAPP-FUNC-001", "GAPP-FUNC-002"],
  "inject_assets": [
    {
      "type": "audio",
      "file": "assets/voice-message-zh.m4a",
      "pod": "k1"
    }
  ],
  "timeout_sec": 1800,
  "callback_url": "https://admin.example.com/callback"
}
```

**响应**:

```json
{
  "task_id": "task-20260806-001",
  "status": "queued",
  "created_at": "2026-08-06T14:00:00Z",
  "estimated_duration_sec": 1800
}
```

### 3.2 查询任务状态

```
GET /api/v1/tasks/{task_id}
```

**响应**:

```json
{
  "task_id": "task-20260806-001",
  "task_name": "语音消息功能验证",
  "status": "executing",
  "progress": {
    "total_cases": 2,
    "completed_cases": 1,
    "current_case": "GAPP-FUNC-002",
    "current_step": "按 AI 键唤醒语音助手"
  },
  "started_at": "2026-08-06T14:00:05Z",
  "elapsed_sec": 120
}
```

### 3.3 获取任务结果

```
GET /api/v1/tasks/{task_id}/result
```

**响应**:

```json
{
  "task_id": "task-20260806-001",
  "status": "completed",
  "result": {
    "passed": true,
    "total_cases": 2,
    "passed_cases": 2,
    "failed_cases": 0,

  },
  "cases": [
    {
      "case_id": "GAPP-FUNC-001",

      "passed": true,
      "duration_sec": 30,

        "/api/v1/reports/task-20260806-001/screenshots/guardian/step-001.png"
      ]
    }
  ],
  "report_url": "/api/v1/reports/task-20260806-001/report.html"
}
```

### 3.4 列出测试用例


## 四、实时界面设计

### 4.1 Pod 实时屏幕

管理后台通过 WebSocket 推流,实时查看 Pod 屏幕。

```
WebSocket: ws://test-system/api/v1/pods/{pod_id}/stream
```

**实现方式**:
- 测试系统通过 SDK `screenShot` 定时截图(2-5 FPS)
- 通过 WebSocket 推送给管理后台
- 管理后台前端渲染图片序列

### 4.2 实时日志

```
WebSocket: ws://test-system/api/v1/tasks/{task_id}/logs
```

**推送消息**:

```json
{
  "timestamp": "2026-08-06T14:00:05.123Z",
  "level": "INFO",
  "category": "mua_api",
  "message": "RunAgentTaskOneStep called: run_name=guardian-bind-001"
}
```

### 4.3 实时断言

```
WebSocket: ws://test-system/api/v1/tasks/{task_id}/assertions
```

**推送消息**:

```json
{
  "step": 1,
  "description": "APP 显示激活成功",
  "passed": true,
  "screenshot_url": "/api/v1/reports/task-001/screenshots/step-001.png"
}
```

## 五、管理后台功能模块

### 5.1 测试用例管理

| 功能 | 说明 |
|---|---|

| 用例执行 | 选择用例 + Pod,触发执行 |

### 5.2 Pod 资源管理

| 功能 | 说明 |
|---|---|
| Pod 列表 | 查看所有 Pod 状态 |
| Pod 详情 | 规格、当前任务、历史 |
| Pod 申请 | 申请新 Pod |
| Pod 释放 | 释放闲置 Pod |

### 5.3 任务管理

| 功能 | 说明 |
|---|---|
| 创建任务 | 选择用例 + Pod + 构建 |
| 任务列表 | 查看所有任务 |
| 任务详情 | 实时进度 + 日志 + 断言 |
| 任务取消 | 取消执行中任务 |
| 任务重跑 | 重新执行失败用例 |

### 5.4 报告管理

| 功能 | 说明 |
|---|---|
| 报告列表 | 按时间/类型筛选 |

| 报告对比 | 两次报告对比 |

### 5.5 压测仪表盘

| 功能 | 说明 |
|---|---|
| 压测场景 | 选择场景 + 并发数 |

| Grafana 集成 | 导入 Grafana 仪表盘 |

## 六、权限与安全

### 6.1 权限模型

| 角色 | 权限 |
|---|---|
| 管理员 | 全部操作 |
| 开发者 | 执行测试、查看报告 |
| QA | 全部测试操作、用例管理 |

### 6.2 安全措施

- API 鉴权(JWT / OAuth2)
- Pod 操作审计日志
- 敏感数据脱敏(继承证据链规范)
- 测试账号隔离(沙箱环境)

## 七、部署架构

### 7.1 测试系统部署

```
┌─────────────────────────────────────────┐
│              管理后台(已有)               │
└────────────────┬────────────────────────┘
                 │ RESTful API
                 ▼
┌─────────────────────────────────────────┐
│          测试系统 API 网关               │
│  - 鉴权 / 限流 / 路由                    │
└────────────────┬────────────────────────┘
                 │
   ┌─────────────┼─────────────┐
   │             │             │
┌──▼────┐   ┌────▼────┐   ┌────▼────┐
│ Master │   │ Unit    │   │ Dual    │
│ Agent  │   │ Agent   │   │ Agent   │
└──┬────┘   └────┬────┘   └────┬────┘
   │             │             │
   └─────────────┼─────────────┘
                 │
   ┌─────────────┼─────────────┐
   │             │             │
┌──▼────┐   ┌────▼────┐   ┌────▼────┐
│ MUA   │   │  SDK    │   │  ADB    │
│ API   │   │ Client  │   │ (调试)   │
└──┬────┘   └────┬────┘   └────┬────┘
   │             │             │
   └─────────────┼─────────────┘
                 │
         ┌───────▼───────┐
         │  云手机 Pod 池 │
         └───────────────┘
```

### 7.2 技术栈

| 组件 | 技术选型 |
|---|---|
| API 网关 | Nginx / Kong |
| Agent 服务 | Python(FastAPI) |
| 前端 | React / Vue(管理后台已有) |
| 数据库 | PostgreSQL(任务/用例) |
| 缓存 | Redis(任务状态) |
| 消息队列 | RabbitMQ(任务调度) |
| 对象存储 | TOS |
| 监控 | Prometheus + Grafana |
