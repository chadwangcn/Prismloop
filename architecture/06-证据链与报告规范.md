## 一、证据链设计原则

### 1.1 核心原则

1. **可追溯**:每个测试结果必须可追溯到具体的截图、录像、日志
2. **完整性**:关键步骤必须截图,音视频场景必须录像
3. **脱敏**:所有证据不包含 Token/账号/儿童内容
4. **持久化**:证据存储到 TOS 和本地,避免链接失效
5. **结构化**:证据按 run-id 组织,便于检索和回放

### 1.2 证据类型

| 证据类型 | 来源 | 用途 |
|---|---|---|
| 截图 | MUA ScreenShots / SDK screenShot | UI 状态验证 |
| 录屏 | MUA RecordingUrl / SDK startRecording | 操作过程回放 |
| 按键日志 | SDK getKeyLog | 物理按键事件记录 |
| 音频分析 | ffmpeg 分析录像 | 音量/频率断言 |
| 结构化输出 | MUA StructOutput | JSON 断言 |
| 任务步骤 | ListAgentRunCurrentStep | 执行轨迹 |

## 四、报告生成

### 4.1 HTML 报告

```python
class ReportGenerator:
    """报告生成器"""
    
    def generate_html(self, result, output_path):
        """生成 HTML 报告"""
        template = self._load_template("report_template.html")
        html = template.render(
            run_id=result["run_id"],
            case_id=result["case_id"],
            title=result["title"],
            status=result["status"],
            duration=result["duration_sec"],
            steps=result["steps"],
            dual_assertions=result["dual_assertions"],
            screenshots=self._prepare_screenshots(result),
            recordings=result.get("recordings", [])
        )
        
        with open(output_path, "w") as f:
            f.write(html)
    
    def _prepare_screenshots(self, result):
        """准备截图展示"""
        screenshots = []
        for step in result["steps"]:
            if "screenshot" in step:
                screenshots.append({
                    "step": step["step"],
                    "pod": step["pod"],
                    "path": step["screenshot"],
                    "timestamp": step.get("timestamp")
                })
        return screenshots
```

## 五、脱敏规则

### 5.1 脱敏对象

| 数据类型 | 脱敏方式 |
|---|---|
| Token / Session | 全部替换为 `***` |
| 账号 / 邮箱 | 中间部分替换,如 `t***@lumi.com` |
| 手机号 | 中间 4 位替换,如 `138****8888` |
| 儿童姓名 | 替换为 `<child_name>` |
| 儿童照片 | 不保存或打码处理 |
| 设备 SN | 保留前 4 位,如 `K1-XXXX-***` |
| family_id | 替换为 `<family_id>` |

### 5.2 脱敏实现

```python
class EvidenceSanitizer:
    """证据脱敏器"""
    
    PATTERNS = {
        "token": r"(token|session|authorization)['\"]?\s*[:=]\s*['\"]?[\w-]+",
        "email": r"[\w.-]+@[\w.-]+\.\w+",
        "phone": r"1[3-9]\d{9}",
        "child_name": r"[\u4e00-\u9fa5]{2,4}",
    }
    
    def sanitize_text(self, text):
        """脱敏文本"""
        for key, pattern in self.PATTERNS.items():
            text = re.sub(pattern, self._mask(key), text)
        return text
    
    def sanitize_screenshot(self, image_path, regions_to_mask=None):
        """脱敏截图(打码特定区域)"""
        if regions_to_mask:
            from PIL import Image, ImageFilter
            img = Image.open(image_path)
            for region in regions_to_mask:
                cropped = img.crop(region)
                blurred = cropped.filter(ImageFilter.GaussianBlur(10))
                img.paste(blurred, region)
            img.save(image_path)
    
    def _mask(self, key):
        return {
            "token": "***",
            "email": "t***@lumi.com",
            "phone": "138****8888",
            "child_name": "<child_name>"
        }[key]
```

## 六、证据下载与持久化

### 6.1 TOS 链接有效期

TOS 截图/录像链接默认有效期 24 小时,需下载到本地持久化。

### 6.2 下载策略

```python
class EvidenceDownloader:
    """证据下载器"""
    
    def download_evidence(self, run_id, evidence_manifest):
        """下载所有证据到本地"""
        local_dir = f"reports/{run_id}"
        
        # 1. 创建本地目录
        os.makedirs(f"{local_dir}/screenshots/guardian", exist_ok=True)
        os.makedirs(f"{local_dir}/screenshots/k1", exist_ok=True)
        os.makedirs(f"{local_dir}/recordings", exist_ok=True)
        
        # 2. 下载截图
        for pod_type in ["guardian", "k1"]:
            for ss in evidence_manifest["evidence"]["screenshots"][pod_type]:
                local_path = f"{local_dir}/{ss['local_path']}"
                self.tos_client.download(ss["url"], local_path)
        
        # 3. 下载录像
        for pod_type in ["guardian", "k1"]:
            rec = evidence_manifest["evidence"]["recordings"][pod_type]
            local_path = f"{local_dir}/{rec['local_path']}"
            self.tos_client.download(rec["url"], local_path)
        
        # 4. 脱敏处理
        self.sanitizer.sanitize_directory(local_dir)
```

## 七、日志规范

### 7.1 日志分类

| 日志文件 | 内容 |
|---|---|
| `mua_api.log` | MUA OpenAPI 调用记录(请求/响应/耗时) |
| `sdk_event.log` | SDK 事件记录(按键/点击/多点触控) |
| `assertions.log` | 断言执行记录(通过/失败) |
| `pressure.log` | 压测指标记录 |

### 7.2 日志格式

```

[2026-08-06T14:00:05.456Z] [DEBUG] [mua_api] Request: {"RunName": "...", "PodId": "..."}
[2026-08-06T14:00:35.789Z] [INFO] [mua_api] Response: run_id=run-xxx, duration=30.3s
[2026-08-06T14:00:36.000Z] [INFO] [assertion] Step 1: "APP 显示激活成功" - PASSED
[2026-08-06T14:00:36.100Z] [INFO] [sdk_event] sendKeyCode(67) on pod-k1-01
```
